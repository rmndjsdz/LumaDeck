# Visión de LumaDeck

La navegación es el producto.

- Cada interacción debe sentirse inmediata.
- Una pantalla nueva no implementa navegación.
- El framework proporciona mouse, teclado y gamepad.
- El foco nunca debe perderse mientras existan elementos válidos.
- Las animaciones no sacrifican FPS.
- La aplicación funciona localmente.
- La simplicidad gana.
