# LumaDeck

Base del proyecto de escritorio LumaDeck con Tauri 2, React, TypeScript y Vite.

## Desarrollo

```bash
npm install
npm run dev
```

Para abrir la aplicación Tauri durante el desarrollo:

```bash
npm run tauri:dev
```

## Validaciones

```bash
npm run typecheck
npm run lint
npm run test
npm run build
cargo check --manifest-path src-tauri/Cargo.toml
```
